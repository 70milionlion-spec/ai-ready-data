خطأ واجهته اليوم:

استخدمت الأمر git remote -V بحرف V كبير، فظهر خطأ لأن الخيار الصحيح لعرض معلومات المستودعات البعيدة هو -v بحرف v صغير.

كيف تم حل الخطأ:

راجعت صيغة الأمر واستخدمت الأمر الصحيح:

git remote -v

بعد ذلك ظهرت معلومات المستودع البعيد origin المرتبط بمستودع GitHub بشكل صحيح.

ما تعلمته:

خيارات Git حساسة لحالة الأحرف، لذلك يجب كتابة الأوامر والخيارات بالشكل الصحيح.
